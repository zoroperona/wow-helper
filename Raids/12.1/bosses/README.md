## 编号约定

- H1-H8 沿用现有攻略和机制测试卷编号，因此 H3 是瓦什尼克、H4 是迷失的探险者。
- 游戏数据库的冒险指南显示顺序将迷失的探险者列为第三、瓦什尼克列为第四；本目录不跟随该顺序，以免团内口令混乱。
- H9 是潮缚石窟的独立团队首领，不属于烈毒之渊。

## 文档状态

- `initial-guide.md`：依据数据库、现有攻略和测试资料形成的初版方案，尚需正式服日志与实战校正。
- 每份手册末尾的数据库技能清单由 `generate-db-skill-appendices.mjs` 生成，数据源为 `wow-db/output/wow.sqlite`，英雄团队难度编号为 15。
- 技能清单以数据库英雄难度可达章节去重；同名但技能编号不同的条目会分别保留。
